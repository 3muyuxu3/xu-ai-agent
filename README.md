1）Java 21 + Spring Boot 3 框架
2）Spring AI + LangChain4j
3）RAG 知识库
4）PGvector 向量数据库
5）Tool Calling 工具调用
6）MCP 模型上下文协议
7）ReAct Agent 智能体构建
8）Serverless 计算服务
9）AI 大模型开发平台百炼
10）Trae AI 代码生成
11）SSE 异步推送
12）第三方接口：如 SearchAPI / Pexels API
13）工具库如：Kryo 高性能序列化 + Jsoup 网页抓取 + iText PDF 生成 + Knife4j 接口文档
